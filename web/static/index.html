How It Works

Graph Coloring (Primary)
Events are vertices. Events sharing students get an edge. Each time slot is a color. The scheduler assigns different slots to connected events — a valid graph coloring.
Set Intersection (Supporting)
P(A) ∩ P(B) — if two events share participant IDs, they form an edge. A clash happens only when they also overlap in time.
Conflict-degree Heuristic
Events with more graph edges are assigned first — they have fewer free slot choices. This is a scheduling difficulty measure, not importance.
Venue Buffer
A venue is locked from session start until end + buffer (25 or 30 min). Prevents back-to-back bookings without reset time.
